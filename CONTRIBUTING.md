# Contributing

Thank you for improving Scripture.

## Development

1. Install Node.js 20 or newer and run `npm install`.
2. Create a focused branch for the change.
3. Keep command IDs, persisted settings, Markdown formats, and public API methods backward compatible.
4. Add or update tests for parsing, formatting, or migration behavior.
5. Run `npm run check` before opening a pull request.

For interactive behavior, also test the affected workflow in an Obsidian development vault on every platform available to you. Include reproduction and verification steps in the pull request.

## Reports and proposals

Bug reports should include the Obsidian version, plugin version, platform, reproduction steps, expected behavior, and relevant console errors. Discuss breaking changes or new external dependencies before implementing them.
